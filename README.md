# 我的理財實驗室

繁體中文、手機優先的財務教育網站。四個核心工具：目標倒推、長期複利、家庭預算與退休提領。所有計算在瀏覽器執行，不連接行情 API、家庭表單只在目前瀏覽器的同一網站網址暫存，可清除；不將財務資料上傳。完整需求與後續階段見 [PRD.md](PRD.md)。

## 本機預覽

需要 Node.js 24（見 `.nvmrc`）。

```sh
npm ci
npm run dev
```

依終端顯示的網址開啟瀏覽器。開發伺服器預設使用 5173 埠；只供開發預覽。正式建置可在本機檢查：

```sh
npm run build
npm run preview
```

本階段沒有部署 GitHub Pages，也沒有發布 workflow。Vite 使用相對資源路徑以支援靜態子目錄，未來正式發布仍需獨立確認。

## 第一階段範圍

- 目標倒推：整元月投入、兩階段投入、銀行比較、起始市值／新增本金／假設收益、逐年明細。
- 長期複利：1～40 年期間、最多三檔 ETF 市值來源、完整／聚焦縱軸及10／20／30 年結果、中途調整投入、ETF／銀行／本金曲線、晚 5／10 年開始比較（本金差異明示）。
- 家庭規劃：互斥月薪／年薪與月平均說明、四類貸款到期、逐月／逐年現金流、自訂未來收入／支出變動、快速雙總額／19 項明細互斥來源、分類警示、七類分配環圈與其他儲蓄對帳、大型購物雙模式與獨立旅遊基金、家庭收支健檢與ETF金額規劃（0元預設、10%快捷）、投資現金收入互斥設定、負值日月結餘。
- 退休提領：資產推提領／缺口推資產、固定實質／當期比例／固定名目、通膨、名目／實質資產、資產不足、報酬順序風險、逐年明細。
- 每個工具均提供基本結果、可展開分析、重設與複製摘要；無效值顯示錯誤。

第二階段的年齡、薪資成長與生活費通膨整合預測，以及第三階段購屋能力與相同總本金公平比較，保留在 PRD，等待使用者確認後實作。

## 結構與假設

- `src/lib/finance.ts`：投資／退休計算純函式；金額上限 NT$ 1 兆，避免極端輸入溢位。
- `src/lib/budget.ts`：家庭收入、預算、分配與逐期預測純函式。
- `src/lib/health.ts`：共同分類帳、CFPB 50／30／20、可調細項上限、健檢順序與資料來源。
- `src/hooks/useBudgetForm.ts` / `src/lib/budgetStorage.ts`：編輯草稿與有效計算值分離、家庭資料本機暫存及安全恢復／清除。
- `src/lib/numberInput.ts`：千分位格式、嚴格數值解析與游標位置計算。
- `src/lib/finance.test.ts`：計算與邊界測試。
- `src/components/ui.tsx`：共用欄位、結果、圖表、數據表與風險提示。
- `src/pages/`：四個工具介面；`tests/` 為瀏覽器驗收。

投資按有效年化率換算月率、月底投入；退休按年初提領、年末報酬。總報酬含股息，不重複加計。累積試算不含通膨，退休另依輸入通膨折算。家庭圖表是月現金流，不是累積資產；年度值逐月加總，另列平均月額。每日值依各期實際天數。ETF 以使用者填入的月金額完整扣除一次，超額保留負結餘並警示，不自動降低。

投資累積預設 8% 僅為教育假設，並非 ETF 保證報酬；銀行與退休預設不變。家庭月薪含獎金與年薪模式均標示月平均，不代表逐月實際入帳。股息可選納入或再投入，兩者互斥；不含未實現價差。

金額欄位即時顯示千分位，允許小數及編輯中負號，並維持游標。無效值顯示錯誤，不參與計算。

這些是教育性情境，不是投資建議、實際歷史績效或安全退休保證。未納入稅費、交易成本及極端市場風險。

## 家庭收支健檢參考

CFPB 50／30／20 採稅後可支配收入，分類可調且每筆只歸一類，剩餘金錢不自動當成已儲蓄。細項上限是本站自訂教育性參考，不是 CFPB 或其他機構的正式標準。緊急預備金參考為 3～6 個月必要支出，系統沒有流動儲蓄資料，不判定是否達標。退休說明改為兩項自我勾選，無退休儲蓄比例、稅前收入或雇主提撥欄位；詳細退休分析前往第四單元。四個原始資料來源列於功能三頁底及 PRD 第 6.8 節。

## ETF 編輯與家庭本機資料

ETF 欄位可暫時空白，失焦／Enter 才驗證；空白完成後在欄位旁提示，超界值同樣提示，沿用最近有效金額且不卸載結果。合法數字即時更新。家庭表單透過版本化 localStorage 自動保存合理值，含財務安全自評；僅限目前瀏覽器與同一網站網址，不上傳 GitHub 或伺服器。「清除已儲存資料」會重設家庭表單並移除記錄，再次編輯才重新保存。瀏覽器拒絕存取時仍可試算，但重整可能無法恢復。

大型購物可指定期限（向上取整月存）或固定月存（倒推月數）；最後一期不超過尚缺資金，與旅遊、ETF、其他儲蓄各計一次。50／30／20 警示使用同一稅後分母，儲蓄低於10%的黃色是本站提醒、非CFPB標準；赤字時不因儲蓄比例達標而給整體良好判定。

四單元共用 `useNumericDrafts` 與 `numericDraft.ts`：有效數字即時更新，編輯中空白或非法值保留最近有效結果，失焦才顯示錯誤，切換單元保留草稿。`portfolio.ts` 封裝三檔市值及縱軸範圍；`living.ts` 定義 19 項生活費。七類環圈不含其他儲蓄，但其他儲蓄仍扣款並單列對帳：七類合計＋其他儲蓄＝收入＋赤字缺口。

## AI 個人化理財教練

功能三最下方可複製四種分析 Prompt（健檢、預算、ETF、退休），或只複製完整摘要。文字直接沿用有效家庭試算，快速模式不輸出未採用明細；未知資料與安全自評皆明確標示。貼到使用者選擇的 AI 工具後才會進行分析，本網站沒有 AI API 或資料傳送。剪貼簿失敗可展開全文手動複製，分享前請檢查個人財務資料。

19 項生活費明細採緊湊雙欄，低於 360px 單欄，快速模式不變。`householdSummary.ts` 格式化既有結果；`coachPrompts.ts` 保存四種任務與共同教育限制。
