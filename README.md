# 我的理財實驗室

繁體中文、手機優先的財務教育網站。四個核心工具：目標倒推、長期複利、家庭預算與退休提領。所有計算在瀏覽器執行，不連接行情 API、不儲存或上傳財務輸入。完整需求與後續階段見 [PRD.md](PRD.md)。

## 本機預覽

需要 Node.js 24（見 `.nvmrc`）。

```sh
npm ci
npm run dev
```

依終端顯示的網址開啟瀏覽器。開發伺服器預設使用 5173 埠；只供開發預覽。正式建置可在本機檢查：

```sh
npm run build
npm run preview
```

本階段沒有部署 GitHub Pages，也沒有發布 workflow。Vite 使用相對資源路徑以支援靜態子目錄，未來正式發布仍需獨立確認。

## 驗證

```sh
npm test                # Vitest 財務計算單元測試
npm run build           # TypeScript 型別檢查與 Vite 正式建置
npx playwright install chromium
npm run test:e2e        # 1440px 桌機與 375px 手機瀏覽器驗收
```

雲端環境已有系統 Chromium 時，可省略下載並執行：

```sh
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e
```

## 第一階段範圍

- 目標倒推：整元月投入、兩階段投入、銀行比較、起始市值／新增本金／假設收益、逐年明細。
- 長期複利：10／20／30 年結果、中途調整投入、ETF／銀行／本金曲線、晚 5／10 年開始比較（本金差異明示）。
- 家庭預算：月薪／年薪、獎金分列、生活費總額或明細、房貸／信貸／其他貸款到期、購車與旅行基金、投資與儲蓄、赤字及緊急預備金參考。
- 退休提領：資產推提領／缺口推資產、固定實質／當期比例／固定名目、通膨、名目／實質資產、資產不足、報酬順序風險、逐年明細。
- 每個工具均提供基本結果、可展開分析、重設與複製摘要；無效值顯示錯誤。

第二階段的年齡、薪資成長與生活費通膨整合預測，以及第三階段購屋能力與相同總本金公平比較，保留在 PRD，等待使用者確認後實作。

## 結構與假設

- `src/lib/finance.ts`：無副作用的計算純函式；金額上限 NT$ 1 兆，避免極端輸入溢位。
- `src/lib/finance.test.ts`：計算與邊界測試。
- `src/components/ui.tsx`：共用欄位、結果、圖表、數據表與風險提示。
- `src/pages/`：四個工具介面；`tests/` 為瀏覽器驗收。

投資按有效年化率換算月率、月底投入；退休按年初提領、年末報酬。總報酬含股息，不重複加計。累積試算不含通膨，退休另依輸入通膨折算。家庭預算圖表是時點月現金流，不是累積資產；年度餘額為目前月配置的簡化年化估算。

這些是教育性情境，不是投資建議、實際歷史績效或安全退休保證。未納入稅費、交易成本及極端市場風險。
